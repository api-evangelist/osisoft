> **Acquired or rebranded.** This company was acquired, merged or renamed. Its API, if it still exists, is offered under another name. This profile is kept as a historical record and is not maintained or rated.

OSIsoft was the enterprise software company behind the PI System, the operational data infrastructure used across manufacturing, energy, utilities, oil and gas, and other industrial sectors to collect, historize, contextualize, and visualize high-volume real-time sensor and control-system time-series data. Its developer surface centered on the PI Web API (a RESTful interface to the PI Data Archive and Asset Framework), AF SDK, and the PI Square developer community. OSIsoft was acquired by AVEVA in 2021; all osisoft.com and docs.osisoft.com properties now redirect to AVEVA, where the product ships as the AVEVA PI System. This profile is maintained as a historical/acquired-company record in the API Evangelist network, with developer resources pointing at the live AVEVA successor pages.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages.
